### New
- **Talkies screensaver.** A clock with seconds, the date and the weather, over your wallpaper or the picks if you like. Pick it in the TV's Settings → Screen saver, then select **Talkies settings → Screensaver**.
- **Board screensaver.** A split-flap board, like a station's departures board. Select **Talkies settings → Screensaver → Board**.
- **Screensaver message.** Two short lines typed on your phone. Select **Talkies settings → Screensaver message**.
- **A device turns on.** A console or box that switches on gets a card to switch to it. Select **Talkies settings → A device turns on**.
- **Edit inputs.** Name an HDMI port or hide it. Select **Talkies settings → Edit inputs**.
- **Weather without setup.** Until you set a location, Talkies goes by your internet address. Select **Talkies settings → Keys and location → Weather location**.

### Changed
- **Blurred art.** The focused picture, blurred, behind Home. Select **Talkies settings → Background**.
- **Bigger apps.** Dock size goes down to 4 apps, and All apps can show 6, 5 or 4 across. Select **Talkies settings → Dock size** or **All apps size**.
- **Continue apps.** Choose which apps show in Continue and Watch Next. Select **Talkies settings → Continue apps**.
- **Focus: Lift or Ring.** A white outline on what's selected, for busy wallpapers. Select **Talkies settings → Focus**.

### Fixed
- **Updates.** Talkies comes back after an update, and says so when a box can't install one.
- **Send from your phone.** The QR code page now works on any home network.
